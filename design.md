# M Beauty Salon & Nails — Design System

## Design intent
Create a structured, token-driven, content-first marketing site for M Beauty Salon & Nails, adapting the supplied Sam's Threading system to a premium Cebu beauty-salon experience.

## Foundations
- Primary font: Open Sans, system fallback stack.
- Display font: Playfair Display for editorial headings.
- Base size: 16px; line height: 24px.
- Primary text: #1a1a1a.
- Inverse text: #ffffff.
- Raised surface: #f5f9ff.
- Strong surface/accent: #c9a84c.
- Default border: #aacafd.
- Strong border: #e5e7eb.
- Spacing must use the supplied 4/8/12/16/20/28/32/40px scale.
- Radius must use 4/6/12/16/9999px tokens.

## Components
Header, hero, service cards, about block, gallery, review block, booking form, contact block and footer must maintain responsive behavior and visible focus states.

Interactive elements must support keyboard, pointer and touch input. Buttons must use descriptive labels. Forms must provide labels, required validation and status feedback.

## Accessibility
WCAG 2.2 AA is the target. Focus-visible indicators must remain visible. Text must maintain sufficient contrast. Images must use descriptive alt text unless decorative. Reduced-motion preferences must be respected.

## Content
Tone must be concise, confident, welcoming and beauty-focused. Avoid unsupported claims, fabricated customer testimonials, or unverified service pricing.

## Demo notes
Unsplash imagery is placeholder imagery for client review and should be replaced with salon-owned or approved photography before production. Google rating and business details should be reverified before launch.

## QA checklist
- [ ] Desktop and mobile layouts tested.
- [ ] Keyboard navigation works through all controls.
- [ ] Focus indicators visible.
- [ ] Booking form validation works.
- [ ] No horizontal overflow at mobile widths.
- [ ] Images have appropriate alt text.
- [ ] Google Maps link opens correctly.
- [ ] Business details verified before production.
